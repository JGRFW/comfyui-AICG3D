# 成品图动态控制

## 核心任务

把已经完成的东方巨构图片转成约5秒的中文单镜头视频提示词。视频只激活原图，不重新设计原图。

必须继承：

- 人物数量与衣服颜色
- 人物所在位置
- 建筑结构和主体位置
- 平台、桥面和栏杆边界
- 云海原有范围、高度和体积
- 光线方向和整体构图
- 原图已有动物、瀑布、树木和器物

禁止新增建筑、人物、动物、道具、云层、巨月和剧情事件。

## 运镜选择

每条只选择一种缓慢运镜，不切镜，不组合：

- 缓慢推进：适合中轴道路、远方宫门和内部纵深
- 缓慢后拉：适合逐步揭示整体尺度和框景关系
- 缓慢向左横移或向右横移：适合侧面长廊、横向宫城和瀑布
- 向左小幅环绕或向右小幅环绕：适合单一平台、古松、巨钟和人物观景

运镜幅度保持克制，不能改变原图主体比例和空间关系。

## 人物状态

人物整段只保持一种状态：

- 原图人物静立：始终站立
- 原图人物坐着：始终坐着
- 画面需要行走：缓慢走向一个明确方向

不要写“持续行走”，不要写“走两步停下”，不要在同一镜头中改变人物状态。衣袍只写“轻轻飘动”或“向后轻轻飘动”。原图没有道具时不新增道具。

方向必须具体：沿长廊缓慢向左走、沿天桥缓慢走向远方宫殿、从画面下方向门洞缓慢前行。

## 云海稳定运动

画面存在云海时，正文必须包含四项：

1. 原有云海内部低幅度缓慢翻涌
2. 表层云纹向一个明确方向平稳移动
3. 近处稍快、远处更慢，形成自然视差
4. 云海整体高度、边界和体积保持稳定

默认通用写法：

```text
原有云海以清晰可见的低幅度缓慢翻涌，表层云纹由右向左平稳移动，近处云峰缓慢隆起后回落，远处云层以更慢速度同向流动，形成自然视差。云海整体高度、边界与体积保持稳定，不新增云团，不升高，不撞击或遮挡人物、平台和建筑。
```

允许根据构图把方向改成由左向右，但必须确定一个方向。

禁止表达：

- 大范围翻涌
- 猛烈翻涌
- 云浪涌向平台
- 从桥下升起
- 穿过宫殿
- 薄雾围绕建筑
- 巨大云浪拍击
- 云层撞击平台

这些表达会导致新增云区、抬高云层、遮挡建筑或重新生成平台边界。

## 原图物体动态

每条最多增加一件原图已有物体的动态：

- 古松：松枝轻轻摆动
- 瀑布：沿原有路径向下流动
- 仙鹤：停在原处轻动羽毛，或沿原有飞行方向缓慢滑翔
- 鲸鱼：在原有位置缓慢游动，不改变体型和距离
- 巨钟：轻微摆动
- 衣幔：沿同一方向轻轻飘动
- 水面：原有倒影产生轻微波纹

没有清楚物体时不强行增加动态。光影只允许低位晨光或夕光产生轻微明暗变化，不能改变时间段。

## 提示词结构

按以下顺序写成一段：

1. 人物状态与明确方向
2. 一种缓慢运镜
3. 原有云海内部运动
4. 一件原图已有物体的轻微动态

不写声音、音乐、字幕、画质参数、摄影机品牌和焦段。

## 输出格式

```text
### 01｜场景名称

人物状态与动作。镜头缓慢推进、后拉、横移或小幅环绕中的一种。原有云海低幅度缓慢翻涌，明确移动方向、近远速度差与稳定边界。原图已有的一件物体产生轻微动态。
```

## 输出前自查

- 是否只使用一种运镜
- 人物是否整段保持一种状态
- 行走方向是否明确，并使用“缓慢走”
- 是否没有新增道具、动物、建筑和剧情
- 云海是否只在原有范围内部运动
- 是否写明表层移动方向和近远速度差
- 是否锁定云海高度、边界与体积
- 是否没有“云浪撞击平台”等重绘风险词
- 是否只增加一件原图已有物体动态
- 是否没有声音、音乐和摄影参数
