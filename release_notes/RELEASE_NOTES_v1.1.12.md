# comfyui-AICG3D v1.1.12

本次更新重点解决工作流分享后参考素材路径失效的问题，避免图片、音频或视频已经丢失时仍然静默显示为空块。

## 更新内容

- 工作流加载后自动批量检查所有 AICG3D 素材引用。
- 缺失素材会在资源卡片上显示红色“素材缺失”标记。
- 会明确指出缺失素材所属的视频段落，例如“视频段落 1、2”或“视频段落 3”。
- 弹出确认框汇总缺失文件，并支持一键移除所有失效引用。
- 后端执行视频段落时，内嵌素材读取失败会带上“视频段落 N”的错误上下文。
- 新增 `/aicg3d/api/media/validate` 批量校验接口。
- 版本号提升至 `1.1.12`。

## 使用方式

打开工作流后如果存在缺失素材，插件会显示缺失文件清单：

- 点“确定”：自动清理无效素材引用。
- 点“取消”：保留引用和红色缺失标记，便于手动重新上传或替换素材。

素材文件本身不会嵌入工作流 JSON，分享工作流时仍建议同时打包 `ComfyUI/input` 中使用的图片、音频和视频文件。
