# H3 Ref2VA 双格式编译合同

本合同把既有中文母稿编译为 MiniMax H3 Ref2VA 英文六段稿。它不替换、不翻译重写、不简化中文母稿的导演逻辑；英文稿只是同一条战斗的模型执行表达。

## 1. 读取与交付顺序

编译前必须阅读 `$h3-prompt-writing` 的 `SKILL.md` 和 `references/ref-en.txt`，以该 Skill 的字段、标签、关系标记和时间写法为准。

最终固定输出顺序：

1. **中文通用视频提示词**：以 `BUNNY` 作为第一个词；约 15 秒遵守 `15s-fight-directing-contract.md` 的七段结构，10 秒及以内遵守四段短时长结构；不出现 `<Subject N>`、`<Picture N>`、保留关系或英文 H3 字段。
2. **English H3 Ref2VA Prompt**：以独立第一行 `BUNNY` 开始，随后只使用下列六段英文结构，不添加中文解释、负面词栏目或其他标题：

```text
BUNNY

subject_definitions:

summary:

retention_analysis:

detailed_description:

overall_soundscape:

non_diegetic_music:
```

`BUNNY` 是用户指定的模型触发词，不代表角色、道具、动物、字幕、Logo、声音或画面风格；不得在中文或英文正文中解释或视觉化它。

若用户明确“只要中文”，保持中文母稿原样并省略英文稿。若用户要求其他 H3 模式或其他平台，不强行使用本合同。

## 2. 中文母稿不可变规则

英文稿必须继承而不是改变以下事实：

- 角色数量、身份/外观、服装、身体结构、武器、能力、能量规则和持有关系；
- 开场的空间关系与第一处威胁；
- 每个攻击、应对、接触/错失、受力、位移、环境结果和下一动作触发；
- 由时长路由选定的强度曲线、镜头信息任务、优势转换、胜者、败者状态、最终落点和最后余波；
- 对白内容、音效事件与是否存在配乐。

中英文必须拥有相同的镜头数、镜头顺序与切镜时间。中文母稿可以按阶段归组，但每个实际切镜必须在对应阶段内明确标出；英文不得自行拆分、合并或新增 H3 shots。不得因此添加中文稿没有的战斗者、装备、能力、损伤、环境机关或结果。中文母稿始终在前，内容保持原逻辑，不因英文 H3 格式而删短、换序或改成标签稿。

当中文母稿启用“无停顿连续模式”时，英文稿必须原样继承：不得新增 `charge up`、`pause`、`hold`、`brake`、`settle`、`freeze`、`pose` 或静态胜利画面；快慢变化只能改写为动作密度、位移、切镜节奏和摄影机速度的改变。每个 H3 shot 的末尾必须已经进入下一动作，最后一个 shot 也必须保留可见的进行中运动。

## 3. Reference 标签设计

只定义实际复用的可见内容。单张综合参考图通常使用：

- `<Subject 1>`：阵型 A 的身份、脸、发型、体型、服装、可见武器和稳定身体结构，来源于 `<Picture 1>`；
- `<Subject 2>`：阵型 B 的身份、身体结构、服装、可见武器/肢体/能力介质，来源于 `<Picture 1>`；
- `<Subject 3>`：场景的建筑、材质、光源、地形和空间关系，来源于 `<Picture 1>`。

只有图片实际承担关键帧、首帧、尾帧或构图锚点时，才单独定义 `<Picture 1>`。普通参考生成只在各 `<Subject N>` 的来源中引用 `<Picture 1>`，不把它伪装成锁死构图的命令。没有参考视频或参考音频时，不创建 `<Video N>` 或 `<Audio N>`。

`retention_analysis` 使用真实关系：角色、装备和场景的可见事实通常为 `fully_preserved`；仅转移气氛或广义视觉倾向时使用 `weak_reference`；不得把新增动作当成“没有保留”。

## 4. 六段写法

### subject_definitions

每个 `<Subject N>` 单独一行，写清来源、承担的角色及需要保持的关键特征。不要定义未使用的参考标签。

### summary

用一段简短英语开头：`[reference generation]`。概括时长、主体、环境、主因果链、镜头节奏和最终状态，只引用已定义标签。

### retention_analysis

每个标签一行，写明出现的 shot、固定关系标记和保留内容。角色图只保留身份、外形、服装、武器和身体结构时，应明确不把无关站姿或原背景作为强制复刻对象。

### detailed_description

先用一到两句建立画风、光线和总体镜头原则；随后按播放顺序写镜头：

- `[Shot 1]` 不写时间；后续镜头严格写作 `[Shot N] At MM:SS.mmm, ...`，时间递增且不超过总时长；
- 每次切镜必须由接触、错失、位移、遮挡、环境变化或优势转换触发，不能在切镜后重置人物；
- 每个 shot 写清画面位置、主体状态、具体动作、接触或险些命中、受力/位移、环境响应、一个主运镜和镜头落点；
- 每个 `<Subject N>` 首次出现时描述被保留的特征；后续只用同一标签，不重新定义；
- 无对白时不创建 `(S1)` 或 `<d>`。默认明确禁止字幕、标题、Logo、对话气泡和意外可读文字。

### overall_soundscape 与 non_diegetic_music

声音事件必须与中文母稿对应。`overall_soundscape` 只汇总环境与物理声音；`non_diegetic_music` 只写观众听到的配乐，说明乐器、节奏、动态变化。没有配乐时写 `N/A`。

## 5. 编译前静默对照

确认中文和英文均以 `BUNNY` 作为第一个词，并逐项对照时长、角色、武器、能力、场景、动作因果、镜头数量、切镜时间与顺序、接触结果、镜头落点、声音、胜负和最终余波。任何英文新增内容都先回写到中文母稿并重新检查；若不能回写，则删除该英文新增内容。
