# comfyui-AICG3D v1.1.28

![version](https://img.shields.io/badge/version-1.1.28-green)

## 本次更新

### 全局提示词折叠与批量写入

- `AICG3D 分段提示词解析`新增“显示全局提示词”开关，默认折叠，需要时再展开。
- 折叠只隐藏控件，不清空已填写的全局提示词，也不会改变节点宽度。
- 全局提示词统一拼接到每一段前面，可约束画风、角色身份、镜头规则和素材引用。
- “一键填入全部视频段落”只读取节点文本框中的内容，不再自动读取系统剪贴板或覆盖当前文本。

### 逐段预览整合

- 视频段落节点的采样预览与本段视频合并到同一个显示卡片，不再占用两个独立预览框。
- 一采采样过程先显示逐帧预览；本段视频生成完成后，自动切换到本段成片。
- 多段运行时按当前段落逐步更新，不会等到全部段落结束后才出现预览。

### RelayVSR 整片放大

- `AICG-渲染器（高级·加速）`新增可折叠的 RelayVSR 开关、模型、Flash VAE、细节强度和曝光锁定参数。
- `成片高清二采放大`可把 RelayVSR 作为独立整片放大步骤，接在最终合成之后运行。
- RelayVSR 只处理画面，音频始终从原始视频旁路封装，不经过潜空间采样或超分。
- 增加模型与 VAE 的 x2/x4 倍数校验，以及处理前后逐帧亮度锁定，减少超分造成的曝光漂移。
- 未找到模型时提供明确路径和下载要求，关闭开关时不会加载 RelayVSR 模型。

### 工作流与发布

- 同步更新 11 号数字人工作流和 13 号无限长视频相关示例工作流。
- Registry 发布工作流增加 `pyproject.toml` 版本变更自动触发，并继续校验发布包中的前端脚本、后端模块和工作流。

## 验证

- JavaScript 语法检查与 ComfyUI Nodes 2.0 运行时 UI 冒烟测试通过。
- 分段提示词全局写入、折叠高度稳定性和工作流参数顺序检查通过。
- RelayVSR 模型/VAE 匹配、解码推理模式与音轨旁路测试通过。
- 成片二采、逐段预览、工作流节点类型与发布包审计通过。
