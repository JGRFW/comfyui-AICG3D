# 反推提示词模版

> 分类：生图模板与反推 ｜ 来源：反推.MD

请严格复刻我上传的参考视频，不要做二次创作，不要优化剧情，不要改变原视频的导演设计，不要自行增加任何人物、道具、动作、镜头、特效或转场。

目标：
尽可能做到与参考视频在视觉、动作、镜头语言、节奏和时间轴上高度一致。

请先完整观看参考视频，然后按照视频真实内容逐帧分析，不能凭感觉概括。

重点锁定以下内容：

1. 时间轴
   精确拆分每一个镜头的开始时间、结束时间、持续秒数。
   例如：
   0.0—1.8秒
   1.8—3.2秒
   3.2—5.6秒
   必须尽量贴合原视频真实节奏，不得擅自延长或压缩。

2. 镜头数量
   原视频有几个镜头就复刻几个镜头。
   不要新增镜头。
   不要删除镜头。
   不要合并镜头。
   不要为了画面好看自行改变剪辑结构。

3. 景别
   逐镜识别并锁定：
   大远景、远景、全景、中全景、中景、近景、特写、大特写。
   人物在画面中占比必须尽量与原视频一致。

4. 构图
   严格分析：
   人物位于画面左侧、中央还是右侧；
   头顶留白比例；
   人物身体露出范围；
   前景、中景、背景关系；
   主体距离镜头的远近；
   画面水平线位置；
   是否对称构图；
   是否中心构图；
   是否三分法构图；
   是否有前景遮挡。

禁止擅自重新构图。

5. 摄像机位置
   逐镜分析：
   机位高度；
   俯拍、平视、仰拍；
   镜头位于人物正面、侧面、背面还是斜侧面；
   摄像机与人物距离；
   摄影机运动方向。

6. 焦段与透视
   根据画面透视关系判断接近的镜头焦段，例如：
   24mm、35mm、50mm、85mm、100mm。
   重点保持人物脸型、空间压缩感、背景透视与原视频一致。
   禁止使用明显不符合原片的超广角畸变。

7. 运镜
   必须逐镜复刻原视频摄像机运动。

包括但不限于：
固定镜头；
缓慢推近；
快速推近；
拉远；
左移；
右移；
升镜；
降镜；
横摇；
俯仰；
环绕；
跟拍；
手持；
稳定器跟随；
轨道移动；
弧形运动；
甩镜；
突然静止。

必须写清楚：
运动方向＋运动速度＋运动距离＋开始时间＋停止时间。

例如：
“0.0—1.5秒摄影机保持固定；
1.5—3.2秒缓慢向前推进约40cm；
3.2秒人物抬头瞬间停止推进。”

不要只写“镜头推进”。

8. 人物
   如果参考视频中有人物，必须锁定：

性别；
年龄；
脸型；
五官；
发型；
发色；
肤色；
身高；
身材；
服装；
鞋子；
饰品；
妆容；
人物气质。

整段视频必须保持同一个人物身份。

禁止：
换脸；
五官漂移；
年龄变化；
发型变化；
服装变化；
身材变化；
人物突然变成另一个人。

9. 人物动作
   动作必须按照原视频发生顺序逐步拆解。

不要概括成：
“人物走过去拿起东西。”

必须写成：
“右脚先向前迈步 → 身体重心前移 → 左手自然摆动 → 视线转向桌面 → 右手伸向桌面 → 五指张开 → 手指接触杯子 → 握住杯身 → 手腕轻微抬起 → 杯子离开桌面。”

动作发生时间必须与原视频一致。

禁止增加原视频没有的肢体动作。

10. 表情与微表情
    逐镜复刻：
    眼神方向；
    眨眼；
    皱眉；
    嘴角；
    呼吸；
    吞咽；
    停顿；
    惊讶；
    犹豫；
    冷漠；
    紧张；
    笑意；
    眼神变化。

不要只写“人物很紧张”，必须说明紧张具体表现在哪里。

11. 视线
    人物每个阶段看向哪里必须明确：
    看镜头；
    看另一个人物；
    看桌面；
    看手机；
    看门口；
    低头；
    回头；
    侧目。

禁止人物眼神乱飘。

12. 场景
    严格还原参考视频中的：
    空间结构；
    墙面；
    地板；
    桌椅；
    门窗；
    家具；
    背景摆设；
    颜色；
    材质；
    环境深度；
    物体摆放位置。

所有场景物体的位置前后镜头保持一致。

禁止：
场景重构；
家具瞬移；
门窗变化；
背景多出物品；
空间结构前后矛盾。

13. 道具
    逐个识别视频中真正参与剧情的道具。

锁定：
大小；
颜色；
材质；
新旧程度；
摆放位置；
朝向；
人物拿取方式；
使用顺序。

道具前后镜头必须保持连续。

14. 光线
    严格分析参考视频：
    主光方向；
    光线高度；
    冷暖；
    光比；
    人物面部亮度；
    背景亮度；
    轮廓光；
    窗外光；
    灯具光；
    阴影方向；
    高光位置。

不要自行做成“电影感”或者“高级感”，除非原视频本身就是这种风格。

15. 色彩
    参考原视频真实色调复刻：
    曝光；
    白平衡；
    对比度；
    饱和度；
    黑位；
    高光；
    肤色；
    背景颜色。

禁止自行套用其他电影LUT。

16. 景深
    分析主体清晰程度和背景虚化程度。
    保持与原视频相似的光圈与焦平面关系。

17. 对焦
    注明每个镜头：
    焦点在人物脸部；
    焦点在眼睛；
    焦点在手；
    焦点在道具；
    是否发生焦点转移。

如果原视频有拉焦，必须复刻拉焦发生时间。

18. 转场
    严格复刻原视频真实转场：
    硬切；
    遮挡转场；
    运动匹配；
    物体匹配；
    甩镜；
    淡入淡出；
    闪白；
    无缝转场。

如果原视频没有特效转场，不得自行添加。

19. 节奏
    重点分析：
    动作卡点；
    台词卡点；
    音乐卡点；
    镜头切换卡点；
    人物表情变化卡点。

需要明确：
“哪一帧发生什么变化”。

20. 音频
    如果需要连声音一起复刻，请拆分：
    环境音；
    人物对白；
    脚步；
    衣服摩擦；
    物体碰撞；
    呼吸；
    开门声；
    桌椅声；
    音乐；
    音效。

声音出现时间尽量与画面事件完全同步。

最终请输出两个版本：

A.《参考视频逐秒导演拆解》
格式：

镜号｜
时间｜
时长｜
景别｜
焦段｜
机位｜
构图｜
运镜｜
画面内容｜
人物站位｜
人物动作｜
表情与微表情｜
视线｜
场景｜
道具｜
灯光｜
声音｜
转场｜
连续性要求

B.《可直接用于视频生成模型的复刻提示词》

必须按照原视频时间顺序编写：

【0.0—X.X秒】
场景：
人物：
构图：
机位：
焦段：
摄影机运动：
人物动作：
人物表情：
人物视线：
道具状态：
灯光：
声音：
画面结束状态：

【X.X—X.X秒】
继续……

最后增加：

【全局一致性锁定】
人物五官不变；
发型不变；
服装不变；
身体比例不变；
场景结构不变；
家具位置不变；
道具形态不变；
光线方向连续；
动作符合真实物理惯性；
人物运动轨迹连续；
摄影机空间方向连续；
禁止左右镜像；
禁止人物瞬移；
禁止道具瞬移；
禁止凭空增加人物；
禁止肢体畸形；
禁止手指错误；
禁止五官漂移；
禁止画面闪烁；
禁止纹理跳变；
禁止背景重构；
禁止自动重新构图；
禁止AI自行增加慢动作；
禁止增加原视频不存在的运镜；
禁止增加原视频不存在的特效。

核心原则：

不是“生成一个类似的视频”。

而是把参考视频当成导演执行母版。

参考视频中的：
镜头顺序、
每镜时长、
摄影机位置、
运镜轨迹、
人物位置、
人物动作、
动作速度、
表情变化、
视线方向、
场景布局、
光线方向、
道具状态、
剪辑节点

全部作为硬约束进行复刻。

凡是参考视频没有出现的内容，不得自行添加。
凡是参考视频已经确定的内容，不得自行修改。

优先级：
动作一致性 ＞ 镜头一致性 ＞ 人物一致性 ＞ 构图一致性 ＞ 场景一致性 ＞ 光影一致性 ＞ 风格美化。

如果“更好看”和“更像原视频”发生冲突，永远选择“更像原视频”。
