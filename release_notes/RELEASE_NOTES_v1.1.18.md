# comfyui-AICG3D v1.1.18

> 版本日期：2026-10-24
> 本次更新修复其他电脑加载旧版数字人工作流时出现的 RIFE 控件校验错误。

## 问题原因

- 旧工作流的 RIFE 模型、插帧倍率和清缓存值按旧控件位置保存。
- 较新前端或浏览器缓存恢复控件时发生位置错位，三个值被读成 `1`。
- ComfyUI 在节点执行前按新控件类型和范围校验，因此提示输入超出范围、类型错误或选项不适用。

## 兼容修复

- 前端载入旧工作流时，按控件名称和有效范围自动修复数字人 RIFE 参数。
- 后端对三个历史 RIFE 字段启用兼容校验，不再在进入节点前直接拒绝旧工作流。
- 错位或无效值会自动回落到安全默认值：
  - 模型：`rife47.pth`
  - 插帧倍率：`4`
  - 清缓存间隔：`10`
- 正常保存的 RIFE 参数不会被修改。

## 验证

- Python 语法检查通过。
- JavaScript 语法检查通过。
- 旧值 `1 / 1 / true` 能恢复为 `rife47.pth / 4 / 10`。
- 当前 11 号工作流保存的 `rife47.pth / 4 / 10` 保持原值。
