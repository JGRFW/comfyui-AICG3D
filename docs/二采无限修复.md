# 二采 1.0x 无限修复链

`AICG-渲染器（二采放大）` 现在除了原来的 H3 二采，还可以调用独立修复引擎：

- `SeedVR2 视频修复`：推荐。支持时序分块、颜色校准和时间重叠，适合连续多次修复。
- `RTX VSR 超分`：NVIDIA RTX 专用，速度快，适合先做轻量超分；它不具备 SeedVR2 的扩散补细节能力。
- `VOSR2 单帧修复`：单帧超分修复，适合测试或静态感较强的镜头；只支持整数倍。

`DLSS 5` 是游戏运行时由游戏引擎提供深度、运动向量等 3D 数据的神经渲染方案，不是可接入 ComfyUI 后期视频帧的通用节点，因此这里使用 SeedVR2、RTX VSR 和 VOSR2 完成实际视频修复。

## 无限修复怎么接

把每一颗二采节点的 `二采数据` 接到下一颗二采节点的 `一采数据`：

```text
H3 一采
  -> 二采 A：SeedVR2，修复倍数 1.0
  -> 二采 B：SeedVR2，修复倍数 1.0
  -> 二采 C：SeedVR2，修复倍数 1.0
  -> 最终成片
```

选择修复引擎后，当前节点会：

1. 解码上一颗节点传来的视频 latent。
2. 用所选引擎修复这些真实画面。
3. 把修复画面重新编码为 H3 latent。
4. 原样带回一采音频，不重新生成音频。
5. 从 `二采数据` 交给下一颗节点继续修复。

因此 `1.0x` 不再是重复跑一遍 H3 采样，而是后一颗处理前一颗的修复结果。

## 参数建议

- 修复倍数：`1.0` 用于连续修复；需要更高分辨率时可先用 `1.5` 或 `2.0`，后续再接 `1.0` 修复。
- 批次帧数：SeedVR2 推荐 `5`、`9`、`13`，帧数越多时序越稳，但显存占用也更高。
- 时间重叠：推荐 `2`；出现批次边界闪烁时可提高到 `3` 或 `4`。
- 颜色校准：推荐 `lab`，可减少多次修复后的偏色。
- 显存不足：SeedVR2 的 `BlockSwap` 可尝试 `8` 到 `24`，并保持空闲设备为 `cpu`。
- 长视频：保持 `SeedVR2 VAE 分块` 开启，降低编解码显存峰值。

## 模型位置

SeedVR2：

```text
ComfyUI/models/SEEDVR2/seedvr2_ema_3b_fp8_e4m3fn.safetensors
ComfyUI/models/SEEDVR2/ema_vae_fp16.safetensors
```

VOSR2：

```text
ComfyUI/models/vosr2/VOSR2/
```

RTX VSR 需要安装 `comfyui_nvidia_rtx_nodes`，并使用支持 NVVFX 的 NVIDIA RTX 显卡。

如果缺少对应插件或模型，节点只会在这项功能被选中时给出明确提示；修复引擎保持“关闭”时，原来的 H3 二采流程不受影响。

## 使用边界

可以无限增加修复节点，但更多次数不一定无条件让每一帧都更好。扩散修复和超分模型反复处理时，仍可能出现过度锐化、塑料感或纹理漂移。建议每次只修复确实需要的次数，并用 `1.0x + 低强度修复 + 颜色校准` 保持人物和环境稳定。
