生成中式赛博异兽场景，公式教程
这套中式赛博异兽场景核心提示词公式
[核心风格词] + [人物状态/动作] + [异兽状态/动作] + [场景与环境] + [构图与镜头] + [氛围与尺度渲染]

按照这个公式，我们把创作过程拆解为以下四个关键步骤：

第一步：锁定“中式赛博”的灵魂基调
一气呵成的画面，离不开精准的风格定位。在你的提示词最开头，必须牢牢钉住这三个核心关键词：

国风 / 东方奇幻：定下文化基底。

中式赛博 (Chinese Cyberpunk)：引入机械、霓虹或未来科技感。

卷曲纹理 (Curling textures / Auspicious cloud patterns)：这是融合的关键！将传统的祥云、回纹等东方纹理与机械装甲结合，能让赛博感变得“很国风”。

第二步：分治与融合（人物、异兽、场景）
不要一开始就尝试把所有东西揉在一起。在真正生成大场景前，建议先在脑海中（或单独跑图）明确三个主体的形态：

人物：例如“白发战士，身穿红白金相间的赛博机械铠甲”。

异兽：例如“机械飞鲸”、“装甲巨龟”或“机械神虎”。

场景：例如“云海中的悬浮楼阁”或“漫天红枫的赛博城市”。
融合技巧： 明确了这三者后，在最终的提示词中将它们按层次并列写出，确保AI能照顾到画面的每一个元素。

第三步：调度镜头与动作（画面定海神针）
怎么让这三者在画面中和谐共处且具有故事感？你需要用动作词汇和构图词汇来充当“导演”：

动作词汇：写具体！不要只写“站着”，要写“手持长剑，背对镜头站在高台边缘凝视天空”或“机械巨兽张开巨口咆哮向前扑击”。

构图与镜头：这是划分主次的关键。明确指出“前景（人物）”、“中景（建筑）”、“远景/背景（巨兽）”。加入“广角镜头 (Wide-angle)”、“仰视视角 (Low angle)”或“史诗级构图 (Epic composition)”，让空间感彻底拉开。

第四步：注入灵魂“巨物感”
画面平平无奇，往往是因为缺乏比例上的震撼。要在融合时的提示词末尾，加上这些能引发“巨物恐惧症”的渲染词汇：

巨物感 (Sense of gigantic objects)

压迫感 (Sense of oppression)

强烈的体型对比 (Strong size contrast)

遮天蔽日 (Blocking out the sky)
