# comfyui-AICG3D v1.1.27

![version](https://img.shields.io/badge/version-1.1.27-green)

## 本次更新

### 成片级高清二采与画质修复

- 将高清二次采样与画质修复放到全部分段生成、合并完成之后，只处理最终成片。
- 避免每一段独立二采后因首帧状态不一致而在拼接处出现模糊、卡顿、闪烁或曝光跳变。
- 成片高清节点按折叠式设计，需要时展开设置；支持采样、超分修复、设备与预览等参数。
- 音频走独立旁路，不参与二次采样，最终合成时继续使用原音轨。

### 单线成片数据与合成流程

- 最终合成新增 `成片数据` 交接，打包高清二采节点只需一根线即可接入完整成片信息。
- 保留成片视频输出，便于直接预览、保存或继续连接后续画质处理。
- 增加曝光锁定与接缝稳定处理，降低相邻片段的亮度差异和衔接突变。

### 逐段预览与运行反馈

- 视频段落节点提供本段视频与采样预览，按生成进度逐步显示结果。
- 每段完成后再进入下一段，便于及时发现单段问题，不必等到整条成片结束。

### 跨段角色音色锁定

- 固定六角色音色座位支持 `(S1)`～`(S6)` 与 `@角色1`～`@角色6` 引用。
- 同一角色激活后，后续段落继续沿用对应声线与克隆参考；只有明确切换座位时才更换音色。
- 角色显示名可自由修改，不影响固定引用标记。

### 渲染器兼容与保存修复

- `AICG-渲染器（高级·加速）` 的 `高级输入` 开关移动到 `随机种子` 上方。
- 保存工作流时按后端参数定义规范化 `widgets_values`，避免视觉控件顺序与后端顺序不同而导致参数错位。
- 旧版 11 号、13 号工作流可继续读取；原有随机种子、采样器、调度器、步数、二采和预览参数保持不变。

### 工作流与提示词模板

- 同步更新 11 号数字人工作流、13 号无限长视频工作流及参考无限生成工作流。
- 更新无限视频生成提示词模板，继续使用可直接粘贴的分段格式。
