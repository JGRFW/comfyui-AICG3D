# comfyui-AICG3D v1.1.22

![version](https://img.shields.io/badge/version-1.1.22-green)

## 本次更新

### 固定六角色音色库

新增「MiniMax H3 Aicg 角色音色库」节点，提供六个固定角色座位：

1. 女孩
2. 男孩
3. 女主角
4. 男主角
5. 老太太
6. 老爷子

每个角色可独立设置角色显示名、声线描述、语言、年龄、性别、音高和语速。座位编号固定为 1～6，显示名可自由填写。

### 描述音色与参考克隆

- **描述音色**：按座位、性别、年龄、音高、语速和描述关键词生成多声线试听，并把试听文件自动固定为 H3 参考。
- **参考音频克隆**：选择或上传 5～15 秒干净音频，并可设置截取起点和时长。
- 使用克隆音色前必须确认拥有声音使用权或已获得授权。

### 提示词触发方式

在提示词中写入 `@角色1`～`@角色6`，例如：

```text
女主角（@角色3）开口说：<d>[Chinese] 你终于回来了。</d>
```

节点只启用明确提到的固定座位。角色显示名改成任何名字，`@角色N` 都不会变化。旁听或不说话的角色不要写 `@`，避免占用 H3 的参考音频预算。

### 跨段固定与单段抽卡

- 同一 S 编号在所有段落中保持同一条声线，不随机换声。
- 角色音色库节点完全可选：不添加该节点时，前端会清除失效的 `voice_cast` 链接，后端不会从上一段缓存继承旧音色，主 H3 节点和所有视频段落按原来的普通模式运行。
- 角色音色库切换为“克隆音色”时只显示角色名、画面绑定、参考音频上传/截取、授权和试听；固定声线描述、模板、关键词、语言、年龄、性别、音高、语速等描述音色控件会隐藏，切回“描述音色”后恢复。
- 克隆模式不再把隐藏的固定声线描述写入 H3 音色元数据，音色只由参考音频定义，避免文字描述与克隆声音互相冲突。
- 全片完整运行时，音色会顺着段落链传递。
- 单段抽卡时，插件会在提交阶段给当前段显式注入最新音色库连接，避免从上一段缓存继承旧音色。
- 克隆参考音频只作为音色锚点，不复制参考台词，不作为背景音，也不传给其他角色。

### 安全与稳定性

- 固定座位标记使用精确边界匹配，`@角色1` 不会误触发 `@角色10` 或 `@角色1番外`。
- H3 单段最多使用 3 条音频参考；超过时会给出清楚提示。
- 启用克隆音色但缺少图片或视频画面参考时，会提示先添加人物参考图，或改用描述音色。
- 音色配置以静默制作元数据提交，并明确只有 `<d>...</d>` 内的原文可以作为台词发声。

### 音色试听与 11 号工作流

- 每个角色行和编辑区新增“试听”按钮。
- 克隆音色按设置的起点与时长播放参考音频。
- 描述音色使用插件内置 Spark-TTS 节点生成；无需另装 `ComfyUI_SparkTTS`。听到满意的试听文件会直接成为 H3 克隆参考，不再使用系统单声线读稿。
- 11 号多参考·首尾帧·数字人工作流已加入角色音色库。
- 角色音色库节点内新增生成、重新生成、试听、清除生成音色和“应用到提示词”按钮。
- 清除生成音色会恢复描述模式，并删除本插件缓存的试听 WAV。
- 应用到提示词可直接写入 11 号主 H3 节点或 13 号当前视频段落的 `@角色N`。
- 重新生成会在点击时重新读取当前语言、声线描述和参数，不再使用上一次面板渲染的旧值。
- 克隆参考试听按钮可再次点击“停止试听”，并设置强制结束计时，不会一直停留在播放状态。
- 新增角色与图像参考绑定：图像1可以绑定角色2，图像2可以绑定角色4，插入提示词时自动带上对应 `<Picture N>`。
- 绑定会阻止两个角色共用同一张图，并在参考图过滤重编号时同步更新视觉绑定。
- 儿童角色不再沿用中低音：Spark-TTS 强制最高音高并启用内部 `Child` 年龄 token；实测基频由约 203 Hz 提升到约 336 Hz。
- 描述包含“3岁、小女孩、小男孩、幼儿、奶声、童音”时同样按儿童声线生成。
- 新增儿童、少年、青年、成年、中年、老年六档男女声线映射；具体年龄数字优先于关键词和下拉框。
- 描述中的妈妈、爸爸、奶奶、爷爷、少年、中年、老人等词会自动辅助识别年龄和性别，并同步到 Spark 年龄 token 与 H3 音色说明。
- 描述音色重新生成时，Spark-TTS 会直接朗读当前“固定声线描述”的原文，不再朗读固定示例句。
- “固定声线描述”旁新增 12 套男女年龄模板：儿童、少年、青年、成年、中年、老年，每套自动填入描述并同步年龄、性别、音高和语速。
- 新增 18 个快捷关键词标签，点击即可追加到描述文本。
- Spark-TTS 推理源码、节点注册和 5 个内置说话人参考音频已经并入本插件，试听音频保存到 `input/aicg3d_voice_previews`。
- `Spark-TTS-0.5B` 权重仍单独下载到 `ComfyUI/models/tts/Spark-TTS-0.5B`（兼容 `models/TTS`）；角色音色库会显示缺失状态、下载地址和精确缺失文件。
- 内置节点 ID 为 `AICG3D_SparkTTSRun` / `AICG3D_SparkTTSClone`，只有外部 Spark 插件确实不存在时才提供旧 ID 兼容，不覆盖其他插件。
- 数字人锁定音频模式以驱动音轨本身为准；全能参考、纯文本和首尾帧模式可使用角色音色。

### 一键清除全部提示词

- 分段提示词解析节点新增“一键清除全部提示词”。
- 同时清空解析文本、所有视频段落提示词和素材引用文档。
- 保留段落连线、秒数、种子、模型和最终合成设置。
- 清空后不会触发多余的自动填入错误提示。

### 工作流与模板

- 13 号系列工作流已加入角色音色库节点。
- 「无限视频生成提示词模板 V1」增加六角色音色座位、`@角色1`～`@角色6` 触发规则和多角色参考音频限制说明。
