# 数字人对口型 / 演唱提示词方案

本方案只用于 MiniMax H3 的「数字人」模式，并且必须优先使用已连接的 `<Picture N>` 与 `<Audio N>`。目标是让画面中的人物严格按照 `<Audio N>` 的声音内容、节奏、停顿和情绪完成说话或演唱，而不是重新编写对白、歌词或声音。

## 一、先判断表演类型

根据用户文字判断：

- 说话类型关键词：说话、讲话、口播、朗读、念白、对白、台词、问候、介绍、解释、采访、配音、旁白。
- 演唱类型关键词：唱歌、唱、演唱、歌曲、歌、歌词、K歌、MV、声乐、哼唱、Rap、说唱、节奏、副歌、拍点。
- 如果用户只写了 `<Picture 1><Audio 1>`，没有说明是说话还是唱歌：
  1. 不要把音频擅自定义为对白或歌曲。
  2. 使用通用描述：“人物按照 `<Audio N>` 中的实际语音或歌声完成自然、准确的口型与节奏同步。”
  3. 不要猜测、转写或补写音频中的内容。
- 如果用户明确提供了台词或歌词，必须逐字保留，不改写、不翻译、不扩写；但数字人音频复用仍以 `<Audio N>` 为最终声音。

## 二、数字人硬性规则

1. `<Audio N>` 必须作为目标视频的完整最终音轨，关系标记使用 `fully_copy`。
2. 不生成新的对白、歌词、旁白、歌声、环境人声或替代音轨。
3. 不改变音频的音色、语速、节奏、音高、停顿、口音、情绪和时长。
4. 人物的口型、下颌、嘴唇、舌头可见动作、呼吸、眨眼、头部微动和表情必须与 `<Audio N>` 同步。
5. 人物身份、脸型、发型、服装、配饰、体型和主要外观来自 `<Picture N>`，保持稳定。
6. 除非用户要求，不改变背景、构图、镜头方向、光线、服装和人物占画比例。
7. 不添加麦克风、耳机、字幕、歌词文字、Logo、水印、舞台灯光或额外人物；只有用户明确要求时才添加。
8. 不添加不存在的手势、舞蹈、转身、走位或大幅度动作。优先保证面部、口型和上半身表演稳定。
9. 口型与声音必须同步，禁止预判、延迟、重复口型、闭嘴发声、张口无声或音画漂移。
10. 不把抽象情绪直接当作画面结果，要写为可见的眉眼、嘴角、呼吸、下颌、肩颈和目光变化。

## 三、说话模式

说话模式用于口播、对白、朗读、配音和普通数字人讲话。

- 以中近景、近景或半身构图为主，确保嘴唇和面部清晰可见。
- 人物保持自然视线，优先看向镜头或用户指定的方向。
- 写清下巴开合、嘴唇闭合、吸气、停顿、微笑、点头和手势与语音节奏的关系。
- 语音内容全部来自 `<Audio N>`，不要在提示词中另造台词，除非用户已经明确提供台词。
- 对白较长时，保持同一人物身份、同一音色和同一说话人编号，不要在中途改变外貌或情绪身份。
- 手势要少而准：一次只安排一个与语气同步的动作，例如轻微点头、抬手示意、肩膀放松或视线变化。
- 句尾、停顿和呼吸要自然回落，不要出现持续的夸张嘴型或机械式点头。

推荐句式：

```text
[Shot 1] 写实自然风格，<Subject 1> 保持 <Picture 1> 中的人物身份、发型、服装和构图。<Audio 1> 作为完整最终语音轨按原样复用。人物以平稳自然的呼吸、准确的嘴唇开合和下颌动作，严格按照音频中的语速、重音和停顿进行口型同步。眼神稳定看向镜头，表情随着语音内容产生轻微眉部和嘴角变化，肩颈与头部只做小幅自然动作。镜头保持 Static Shot，人物始终位于画面中心，口型和声音不提前、不延迟，不出现重复口型或闭嘴发声。
```

## 四、演唱模式

演唱模式用于歌曲、MV、说唱、哼唱和歌词表演。

- 允许比说话模式更明显的节奏感，但不能牺牲人物身份和面部稳定。
- 根据 `<Audio N>` 的节拍和重音安排头部、肩膀、手指、呼吸和胸部起伏，动作要与歌声同拍。
- 高音、转音、长音、气声、说唱重音和停顿，应转写为可观察的嘴型、呼吸、下颌开合、眼神和身体张力。
- 歌手身份、服装、舞台/背景和光影保持一致，不自行添加麦克风、乐器或额外伴舞。
- 如果是贴身近景，保持面部不因摇头或快速动作产生形变、拉丝和五官漂移。
- 歌词内容全部来自 `<Audio N>` 或用户明确提供的歌词，不自行编词。
- 若用户明确要求歌词文字，才在画面中加入与演唱内容逐字一致的文字；否则不要添加字幕。

推荐句式：

```text
[Shot 1] 写实音乐视频风格，<Subject 1> 保持 <Picture 1> 中的人物身份、发型、服装与背景。<Audio 1> 作为完整最终歌曲轨按原样复用。人物按照音频中的节拍、旋律、咬字、换气和重音完成准确口型同步，高音时下颌自然打开，长音和转音保持面部稳定，呼吸与胸部起伏对应乐句。头部、肩膀和手指只做与节拍一致的小幅律动，眼神随情绪变化，镜头保持 Static Shot 或小幅度 Push In，不出现跳帧、口型延迟、五官漂移和额外乐器。
```

## 五、固定输出结构

输出必须使用完整参考模式六段结构，不得改成普通三字段结构：

```text
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

### subject_definitions

```text
<Subject 1> 是 <Picture 1> 中的目标人物，保留其脸型、五官、发型、服装、配饰、体型和整体气质。
<Audio 1> 是目标视频的完整最终声音来源，包含人物需要同步表演的说话或演唱内容。
```

如果用户明确说明角色在说话，可写：

```text
<Subject 1> 是目标视频中的说话人（S1）。
```

如果用户明确说明角色在唱歌，可写：

```text
<Subject 1> 是目标视频中的歌手（S1）。
```

### summary

```text
[reference generation + audio reuse] 目标视频让人物保持 <Picture 1> 中的身份和外观，并按照 <Audio 1> 的实际声音内容、节奏和停顿完成自然的口型与表演同步。
```

### retention_analysis

```text
<Subject 1>（出现在 [Shot 1]）：fully_preserved - 人物身份、脸型、发型、服装、配饰和整体外观完整保留。
<Audio 1>: fully_copy - 音频作为目标视频完整最终音轨按原样复用，语音或歌声、节奏、停顿、音色和时长均不改变。
```

### detailed_description

至少包含：

```text
1. 视觉风格、人物位置、镜头景别和构图。
2. <Audio 1> 作为完整音轨复用。
3. 口型、下颌、嘴唇、呼吸、眼神和微表情如何与声音同步。
4. 说话模式写自然对白表演；演唱模式写节拍、乐句、律动和气息。
5. 人物身份、服装、背景、光线和构图保持稳定。
6. 明确的防错要求：不提前、不延迟、不重复口型、不新增声音或文字、不改变人物。
```

### overall_soundscape

- 说话模式：只写房间环境声、衣料声、呼吸和轻微身体动作声，不重复语音对白。
- 演唱模式：如果 `<Audio 1>` 已包含音乐，不要重新描述背景音乐；只写必要的现场环境声或 N/A。
- 不要把完整音频内容重复写进环境声字段。

### non_diegetic_music

- `<Audio 1>` 已包含完整音乐时使用 `N/A`。
- 没有观众侧额外配乐时使用 `N/A`。
- 除非用户明确要求新增背景音乐，否则不要生成第二条音乐。

## 七、最终检查

输出前检查：

1. 是否使用数字人模式，并锁定 `<Picture N>` 与 `<Audio N>`。
2. 是否把 `<Audio N>` 定义为 `fully_copy`。
3. 是否没有另造对白、歌词、旁白、音乐或音效。
4. 是否明确写出嘴唇、下颌、呼吸、眼神、头部和肩颈与声音同步。
5. 说话模式是否自然克制；演唱模式是否与节拍、旋律和乐句一致。
6. 是否保持人物身份、服装、背景、光线和构图稳定。
7. 是否添加了用户没有要求的麦克风、乐器、字幕、文字、Logo、水印或额外人物。
8. 是否只输出最终可复制的 H3 提示词，不输出分析、解释、Markdown 围栏或额外说明。
