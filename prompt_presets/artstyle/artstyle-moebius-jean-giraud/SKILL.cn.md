一、核心美学理念
Moebius (Jean Giraud) 风格清新治愈系插画的本质是极繁细节 + 柔润治愈意境的融合，以极致的线条与纹理还原场景、人物、物件的质感，用柔和光影与明快色调营造松弛、温暖的治愈氛围。拒绝杂乱无章的元素堆砌，追求 “繁而有序的舒适感”，让每一处细节、每一缕光影、每一种色彩都服务于整体的治愈调性，既保留 Moebius 风格的艺术线条与极繁特质，又兼具清新插画的温柔与松弛，实现艺术感与治愈感的双重统一。

三、视觉构建核心逻辑（必须严格遵循）
构图与镜头准则
匹配用户指定空间尺度，全景 / 超广角注重场景层次与画面舒展，突出自然与建筑的融合；半身 / 特写聚焦人物 / 核心物件，强化细节与情绪表达；远景侧重意境营造，弱化局部细节，突出整体氛围感。全画幅遵循 Moebius 风格线条特质，笔触清晰有张力，32k 超高清 / 8K、最高画质、细腻渲染 6 级、色彩饱满有质感，还原极繁细节的同时保证画面整体流畅度。
色彩哲学（色即氛围）
春日 / 夏日 → 高饱和度明快色调（明亮绿 / 浅蓝 / 鹅黄），色彩对比柔和，突出生机与清新，画面干净通透初秋 / 深秋 → 中饱和度暖调色系（焦糖橙 / 暖棕 / 酒红），色彩偏温润，突出秋意的温柔与诗意，光影偏柔和斑驳冬日白天 → 低饱和度柔暖色系（奶白 / 暖橙 / 浅粉），冷暖微对比，弱化冬日清冷，突出暖阳的温暖冬日晚上 → 强对比冷暖色系（深蓝 / 藏蓝 + 暖黄 / 暖橙），明暗反差鲜明，以暖光中和冷调，突出宁静温暖的氛围感
光影逻辑（光即情绪）
悠闲慵懒 / 岁月静好 → 漫射柔光 / 斑驳树影，光影层次柔和，无硬影，洒在人物 / 物件上形成轻量明暗，突出松弛感温柔平静 / 宁静温暖 → 侧光 / 逆光 + 局部补光，光影有轻微反差，勾勒人物 / 场景轮廓，边缘带轻量柔光，突出温馨感灵动愉悦 / 童话氛围 → 正面强光 + 光斑点缀，光影通透，高饱和度搭配明亮光线，突出画面的灵动与梦幻孤独静谧 → 低光环境 + 局部暖光，光影反差适中，大面积柔和暗调搭配小范围亮调，突出人物的静谧与孤独
细节与动态构建
材质真实化
植物：叶片脉络清晰、花瓣纹理细腻，绿植有疏密层次，花朵有盛放 / 半开的形态差异物件：藤编家具的编织纹理、木质物件的木纹、布艺的褶皱、陶瓷茶具的釉面质感，还原真实材质触感人物：服装的面料纹理（针织的纹路、纱质的通透、棉麻的粗糙）、发丝的蓬松与层次感，皮肤质感自然柔和
动态捕捉（匹配用户指定额外氛围）
有动态 → 发丝微飘、花瓣轻扬、树叶晃动、云朵缓慢漂移、车辆轻驶、猫咪甩尾，动态幅度轻柔，不破坏整体治愈氛围无动态 → 强化静态细节的质感，人物 / 物件姿态舒展，光影静止，突出画面的静谧与安稳有动物 → 猫咪的慵懒姿态、小鸟的轻飞、蝴蝶的绕身，动物动作与整体氛围匹配，成为画面的治愈点缀
