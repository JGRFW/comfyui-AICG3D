# 来源与授权声明（prompt_presets/）

**本目录内容没有授权信息，请在使用与再分发前阅读本节。**

## 来源

本目录的 144 个提示词模板整理自中文 AI 创作社区公开流传的提示词文档合集，
经过去重、抽取与检索化整理。每个条目的原始出处记录在同级
`meta.yaml` 的 `source:` 字段，汇总记录见本目录 `manifest.json`。

版权归各原始作者所有。本仓库对这部分内容不作任何权利主张，也不将其纳入
本插件的 GPL-3.0-or-later 许可范围。

## 权利人移除请求

如果你是其中任何条目的权利人，并希望它从本仓库移除，请提 issue 说明条目 ID
（例如 `artstyle-moebius`），我们会在确认后立即删除对应条目，无需其他理由。

## 一键移除

不需要这部分内容时，直接删除整个目录即可：

```bash
git rm -r prompt_presets
```

删除后插件正常运行，「提示词模板」页签会显示为空。
