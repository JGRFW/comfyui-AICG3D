# 15 秒高密度打斗导演合同

用于两方主体、参考图驱动、约 15 秒的电影级连续打斗。它把动作导演、武术指导、角色行为和提示词写作分开处理，避免“角色换一套皮也成立”的泛用招式堆叠。

## 0. 时长路由

先按用户指定时长选择结构，再开始动作编排：

- **约 15 秒或未指定时长**：使用本合同的五段状态接力和中文七段母稿；未指定时长默认 15 秒。
- **10 秒及以内**：默认使用四段短时长结构：即时抢攻 → 接触后变线 → 持续追击与攻守转换 → 进行中的切出或用户指定结果。不得把五段终局压缩塞进短片。
- 短时长且未指定胜负时，最后一帧必须仍在攻击、闪避、追击、滑行、卸力或环境连锁中；指定胜负时，最终命中后保留前冲、滑行、追击或卸力，不以摆姿收尾。
- 用户额外要求“无蓄力”“无停顿”“不停”或“全程连打”时，任何时长都叠加无停顿限制：角色、武器、环境物或摄影机至少一项持续运动，禁止收势、制动和静态展示。

## 1. 输入与事实优先级

默认输入包括时长、画幅/画风、各参考图用途、阵型 A/B 的身份或外观称呼、目标、武器、能力、指定动作、战斗风格、能量规律、开场位置、场景、胜负、败者落点、对白和额外限制。

冲突时按以下顺序决定：

1. 用户明确指定的角色、装备、能力、动作、胜负、时间点与禁止项；
2. 参考图清楚可见的外观、服装、持有物、身体结构、能力介质和能量效果；
3. 已确认身份且与当前版本相符的战斗习惯；
4. 保持动作连续性所需的最小补全；
5. 导演原创。

身份不明时使用稳定的外观称呼；不从面部猜测现实身份，不从职业称号自动补武器、门派、招式或能力。

## 2. 参考图与资产账本

逐张为图片分配唯一职责：

- **动作起点图**：继承角色身份、装备、朝向、接触关系、支撑面和空间关系；允许动作和摄影机因真实运动马上改变景别、位置和取景，不把原构图写成必须复刻的命令。
- **角色图**：锁脸、发型、体型、服装、配色、配饰、身体结构和清楚可见的装备；不继承无关背景、站姿或海报构图。
- **场景图**：锁建筑、材质、光源、天气、地形、通道和高低差。
- **海报、拼贴、三视图、设定图**：同一角色的重复出现不增加人数；Logo、文字、水印、边框、背景巨像和装饰不是战斗物体。

为 A/B 分别记录：外形锚点、身体结构、服装、战斗目标、武器种类/数量/材质/尺寸/持握、能力来源、能量规则、移动条件、开场位置和禁止补全项。武器不得无因变形、消失、复制、换手或改变尺寸；无武器角色始终徒手。

若用户明确要求“打斗”但参考图只清楚呈现一名战斗主体，允许为完成双人攻防而补一名**最小化轮廓对手**：不得赋予其独立脸部、服装细节、武器、能力、阵营设定或背景；其默认徒手，并必须在中文与英文母稿中同样标明为导演补全。若用户提供对手设定，则始终以用户设定为准。

超自然能力只在用户明确指定、图片清楚显示，或已确认当前版本具备且不冲突时使用。无能力角色以体态、衣料惯性、空气压缩、尘土、碎石、摩擦和材质破坏表现速度与力量。能力必须写清来源、方向、接触对象和消散/残留结果；不能脱离身体动作凭空爆炸，也不能用大面积特效遮挡攻防。

## 3. 战斗载体自动路由与攻防适配

先按每个主体在参考图中真实可见或由用户明确指定的资产，选择下列唯一主载体；允许组合已经具备的两种载体，例如“徒手＋已确认的雷电强化”或“长剑＋身体冲撞”，但不得为了画面热闹无因补出第三套能力体系。

| 可见条件 | 动作路由 | 关键物理反馈 |
| --- | --- | --- |
| 刃器 | 斩、刺、挑、格、拨、压、绕、滑刃、贯穿；攻击线围绕刃口与剑尖展开。 | 切割轨迹、火花、裂口、断面、刀剑偏转与目标被逼离中线。 |
| 长柄武器 | 中线压迫、远距离刺击、压杆、挑击、横扫、枪尾或柄部短打、折线追刺、回马攻击。 | 必须体现距离优势、杆身转向惯性、回收时间和被贴身后的不利。 |
| 钝器 | 砸、压、推、撞、抡、震击。 | 凹陷、塌陷、碎裂、低频冲击与大幅击退；不写成轻飘飘的剑法。 |
| 远程武器 | 瞄准、发射、追踪、规避、拦截、换位。 | 弹道、射线方向、遮挡关系、发射间隔与掩体结果必须清楚。 |
| 徒手 | 拳、掌、肘、膝、腿、肩撞、擒拿、卸力、翻摔、贴身闪避、踏墙借力与身体冲撞。 | 双手保持空置；持械对手的锋刃必须靠切线、控住非锋利部位、贴身或环境借力处理。 |
| 能力型角色 | 牵引、压缩、塑形、包裹、偏转、束缚、局部强化、环境操控。 | 能力必须从既有身体部位、手势、武器或机械结构产生，写明来源、方向、接触对象与残留。 |
| 飞行生物 | 振翼、收翼、俯冲、翻滚、爪击、空中制动。 | 翅膀结构、升力、气流与转弯半径可信。 |
| 四足或多足生物 | 蹬地、扑击、攀附、撕咬、甩尾、重心转移。 | 足数、关节方向、抓地力与惯性必须正确。 |
| 机械或载具 | 围绕可见推进器、轮组、机械臂、炮口、关节与装甲启动、加速、规避、撞击或制动。 | 不得增加图中不存在的功能；机械反馈来自真实的传动、装甲、轮胎或推进结构。 |

攻防必须再按双方载体差异校验：

- 双方持械：按长度、重量、攻击方向与结构差异设计压制、滑开、缠绕、拆线和反震，不把所有武器写成相同剑法。
- 持械对徒手：徒手方默认侧闪、贴身切入、踢腕、控臂、抓握非锋利部位、肩撞、翻摔或借环境反制；除非用户明确设定，否则不得裸手硬接锋刃。
- 持械对能力：能力方通过有明确来源的局部防御、牵引、偏转、束缚或身体强化处理攻击；写清与武器的接触点和受力结果。
- 双方徒手：只使用拳脚、擒拿、摔投、冲撞和地形借力；不写刀光、剑鸣、枪影或金属碰撞。
- 双方能力：围绕接触、切断、包围、偏转、压缩和环境传播做近中距离攻防；不得退化为无来源的远程光团对轰。
- 生物、机械、巨物或载具：以真实身体或机械结构交锋，不强迫其套用人类剑术、拳术或轻功。

## 4. 四种专业职责

### 电影级动作导演

先确定双方冲突目的、空间主轴、路线节点、危险区、强度升级、第一次逆转、终局落点和每段镜头的信息任务。战斗是单一因果链：抢空间 → 对真实线路反制 → 接触与位移 → 新高度/角度/破绽 → 追击 → 攻守逆转 → 终结与余波。

### 武术指导

按真实载体设计：刃器用斩、刺、格、拨、压、绕与滑刃；长柄体现距离与转向惯性；钝器体现压、砸、推与大幅击退；徒手使用拳掌肘膝、贴身闪避、控臂、翻摔与地形借力；生物、机械和载具必须沿自身结构行动。持械与徒手交锋时，徒手方用切线、控住非锋利部位、贴身或环境借力反制，不裸手硬接锋刃。

每个**关键攻防交换或优势转换**必须完整；同一条连续攻击线内的多次连击可以共同满足下列反馈，避免为每一击强行添加环境破坏：

`起势/重心 → 加速 → 明确攻击线 → 接触或险些命中 → 合理应对 → 形变/反震 → 沿力线位移 → 环境结果 → 下一动作触发`

格挡和落空保留动量并改变下一线路；受击的躯干、护架、脚步、速度和武器控制持续影响后续动作。禁止“完成一招—双方复位—再起一招”。

### 角色行为设计师

每个选择都必须符合目标、性格、体型、风险偏好、当前位置和累计伤势。轻灵者通过切线、变向和借力创造窗口；沉重者通过压迫、撞击、封路和惯性转向建立威胁。双方不是轮流表演：防守针对真实攻击线，反击利用前一动作留下的重心、距离、视野或装备漏洞。最后反击与终结也只能使用既有资产与当前状态。

### AI 视频提示词编剧

只压缩已经成立的导演时间线。约 15 秒中文最终稿固定为七段：项目总述、0—3 秒、3—6 秒、6—10 秒、10—13 秒、13—15 秒、声音与禁止项。10 秒及以内固定为：项目总述、四个连续区间（每个区间标明实际镜头切点）、声音与禁止项。必须写清具体角色、物体、方向、接触、结果和持续状态，不保留方括号、变量名、TODO 或未填写项。

## 5. 五段状态接力

### 0—3 秒：即时开战与首次完整攻防

由更符合当前目标的一方立即抢位，连续使用至少三条不同攻击线。另一方以自身资产完成拦截、闪避、卸力、格挡、偏转、控臂或地形借力。首次接触写清接触点、反震、双方受力方向和第一处破坏；错身后立刻追击。

### 3—6 秒：改变轴线与首次明确命中

继承上一段动量，通过坡面、台阶、残墙、栏杆、屋顶、机械结构或真实移动能力改变高度/通道/方向。无飞行能力者只能通过跳跃、攀附、坠落、弹射、滑行、受击抛飞或环境借力进入空中。明确命中后，受击者必须沿力线飞出、翻滚、滑退、撞物或失衡，并以合理动作恢复。

### 6—10 秒：技术交换与第一次逆转

从仍在滑退、翻滚、坠落或踉跄的状态进入。设计“迫使偏移 → 利用空隙逼近 → 针对载体拆解 → 改用另一已有载体续压 → 利用重心漏洞反震/控臂/切角/翻摔/偏转”的紧密交换。随后把原优势方震开、摔出、迫退或逼入坍塌区，形成明确逆转。

### 10—13 秒：追杀封锁与环境折返

占优方用连续身体动作、武器线路、机械结构或有来源能力封锁路线。被压制方借正在移动的碎石、墙体、栏杆、烟尘或结构折返；穿过每层封锁都出现可读的闪避、擦碰、偏转或方向修正。其从侧面、背面、低位或盲区改变攻击轴线，把对手击入大型结构。

### 13—15 秒：三拍终结与明确结果

败者在受创和失衡中做最后一次符合事实的反击。胜者采用三拍：逼出可预判防御/闪避 → 利用已改变的重心或攻击线变线/换轴/绕侧 → 从真实方向最终命中。写清攻击载体、接触位置、形变与反震、受力方向、最终位移、环境破坏、败者失去战斗能力的可见状态和落点。胜者沿惯性制动，衣料、尘雾、碎石、雨雪、火花或能力余波继续运动到最后一帧。

每次切镜只改变观察角度。下一段至少继承位置、朝向、速度/方向、高度/支撑面、资产状态、受击/优势状态、环境余波中的四项。

### 短时长四段结构与无停顿叠加模式（10 秒或以内）

短时长默认采用四段连续区间，不以 15 秒五段终局收束。未指定胜负时，可在攻防仍持续的状态结束；指定胜负时，结果必须在角色仍在前冲、滑行、追击或卸力时呈现。用户明确写出“无蓄力”“无停顿”“不停”“全程连打”或同义要求时，再叠加无停顿限制：快慢节奏只可通过攻击频率、动作幅度、移动距离、切镜密度、镜头速度和接触密度改变；不得通过角色速度归零、站定、摆姿、凝视、收势、停稳、制动或慢动作展示实现。

推荐按四个连续区间组织：即时抢攻 → 接触后变线 → 持续追击与攻守转换 → 仍在运动的切出或下一次攻击。每个区间的末尾必须已经触发下一段动作；至少一个角色、武器、衣料、碎屑、环境物或摄影机始终持续运动。关键接触可由摄影机短促看清，但角色的身体、武器和攻击链不得为此停止。

短时长未指定胜负时，不得为了给结尾“收束”而擅自制造缴械、跪地、胜者定格或完整制动。无停顿叠加模式下，每个区间末尾必须已经触发下一段动作，最后一个区间也必须保留可见的进行中运动。

## 6. 镜头、物理、声音与禁止项

15 秒模式的五段分别承担：开场冲入接触点、揭示高度与位移、看清技术和重心、追踪封锁与折返、看清终结路线和战场结果。短时长四段依次承担：即时接触、接触后变线、技术交换与优势转换、进行中的切出或指定结果。每镜只用一个主运镜，并写清动作触发、摄影路径、观看焦点和镜头落点。轻微震动、倾斜或重新捕捉必须由撞击、险距或结构受力引起，不能替代主运镜。关键接触只允许摄影机短促稳定以看清接触点，角色与武器随后必须立即沿余势推进；无停顿叠加模式下，摄影机也不得以稳定镜头制造慢拍。

所有接触有重量感：武器偏转/震颤、脚底摩擦、重心失衡、衣料与碎屑延迟响应。破坏符合材质和方向：横击侧向断裂、重砸向下塌陷、穿刺沿贯穿线裂开、撞墙从背部接触点外扩。至少一次环境结果必须改变之后的路线、支撑、遮挡、危险区或优势。

声音只来自可见动作：移动/脚步 → 破风 → 真实材质接触 → 身体受力 → 环境破坏 → 再加速或落地。默认无对白、旁白、字幕、Logo 和可见文字。

禁止开场对峙、原地互殴、动作只有手臂挥舞、攻击无线路或结果、切镜复位、重复招式/构图/运镜/受力/破坏、无依据武器或能力、无依据飞行/瞬移/踏空、身份和装备漂移、纯特效对轰、遮挡核心动作的大特效、无来源冲击波、慢动作停摆、全画面冻结、新增第三名战斗者，以及终结阶段突然出现新武器、新形态或新能力。

无停顿叠加模式额外禁止将“快慢节奏”写成蓄力、停顿、制动、停稳、收势、站定、凝视、稳定展示、胜者摆姿或全员静止。

## 7. 静默检查

输出前检查：

1. 每个角色只使用可见或明确指定的武器和能力；
2. 无武器角色保持徒手，资产归属不串线；
3. 外观、服装、身体结构、持握、能力规律稳定；
4. 每个主体的动作是否符合已选载体，双方是否依照载体差异进行攻防；
5. 每次重要接触具备应对、受力、位移、环境结果和下一动作；
6. 15 秒模式检查五段、短时长模式检查四段的位置、方向、速度、高度、伤势和余波连续；
7. 没有重复动作或无因重置；
8. 声音、能量和破坏均来自画面真实动作；
9. 常规 15 秒模式下，终局胜负、败者状态、落点、胜者制动和最后余波明确；短时长未指定胜负时，检查最后一帧是否仍在可读的攻击、追击、滑行、闪避、卸力或环境连锁中；无停顿叠加模式下，额外检查没有蓄力、收势、制动或静态终局。

若任一项失败，先重写产生问题的上游动作，再输出最终提示词。
