# 3D 动漫风格按视觉美学分类

> 分类：画风与插画 ｜ 来源：提示词人物风格\3D动漫风格按视觉美学-分类\3D 动漫风格按视觉美学-分类.txt

3D 动漫风格按视觉美学、技术手法和题材主题划分，核心类型如下，常融合创新：
一、按视觉与技术划分（核心）
写实风格：高精度建模 + PBR 渲染，还原皮肤纹理 / 布料 / 光影，如《最终幻想 15》CG、《爱死机》；
卡通 / 风格化渲染：
三渲二（Cel-Shaded）：3D 模拟 2D 赛璐璐，黑边 + 色块，《塞尔达：旷野之息》《蜘蛛侠：平行宇宙》；
低多边形（Low-Poly）：几何棱角，《纪念碑谷》《星露谷物语》；
粘土 / 定格风：材质纹理 + 生涩动作，《小羊肖恩》《盒子怪》；
手绘 / 水墨风：笔触晕染，《大闹天宫 3D》《雄狮少年》；
混合风格：写实场景 + 卡通角色（《青春变形记》）、2D 线条 + 3D 空间（《茶杯头》DLC）；
抽象 / 实验风格：几何符号，独立短片 / 广告常用。
二、按题材主题划分
科幻风：未来机械 + 霓虹，《攻壳机动队》；
古风国潮：榫卯 / 汉服 + 青红金，《眷思量》；
萌系 Q 版：二头身 + 软材质，《原神》Q 版；
暗黑奇幻：低饱和 + 金属，《黑暗之魂》CG；
偶像舞台：高光 + 粒子，《Love Live!》3D；
工业 / 教育：精确建模，工程演示 / 医疗动画。
三、按技术特性
实时渲染：游戏 / 虚拟直播（UE5/Unity）；
VR/AR 互动：沉浸视角，《Beat Saber》；
次世代卡通：PBR + 卡通 Shader，《鬼灭之刃》3D 剧场版。
风格无边界，核心是建模、材质、光影、叙事的统一，如《铃芽之旅》3D 场景 + 水彩后期，《赛博朋克 2077》科幻 + 手绘涂鸦，都是创新方向～
