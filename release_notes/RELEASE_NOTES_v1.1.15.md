# comfyui-AICG3D v1.1.15

> 版本日期：2026-10-23
> 本次发布主要面向**目录结构唯一命名空间加固**与**数字人 / 分段替换工作流**的增强。

## ✨ 新特性

- **3D 人物白模节点（`AICG3D_H3WhiteModelRig`）**：从原视频提取人物动作骨架并渲染为白模，作为人物/场景迁移替换的动作参考。
- **分段采样器节点（`AICG3D_H3SegmentSampler`）**：将采样器 + 调度器合并进分段采样流程，支持外部 SAMPLER / SIGMAS / 采样策略输入与分段预览。
- **11 号工作流（多参考·首尾帧·数字人）**：面向数字人场景的多参考与首尾帧组合生成。
- **15 号工作流（分段人物场景动作迁移替换）**：人物/场景替换 → 白模动作迁移 → 分段重采样的完整链路。

## 🚀 性能

- **数字人长音频自动分段**：超长音频自动切段、顺序生成，配合 SelfLift 潜空间放大与跳步复用提速，肉眼质量几乎无感知损失。

## 🐛 修复

- 修复数字人模式渲染报错：`NameError: name 'self' is not defined`（classmethod 内错误引用 `self`，改为 `cls`）。

## 🛠 工程

- **目录结构唯一命名空间加固**：`h3easy/`、`h3goohai/` 迁移至 `aicg3d_h3easy/`、`aicg3d_h3goohai/`，与官方同源插件的加载隔离进一步收紧。
- 新增分段采样预览前端扩展（`aicg3d-sampler-preview.js`）。
- 版本号提升至 `1.1.15`。
