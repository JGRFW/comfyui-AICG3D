# comfyui-AICG3D v1.1.29

![version](https://img.shields.io/badge/version-1.1.29-green)

本版本是一次面向开源发布的完整稳定性、安全性和兼容性维护更新。

## 开源与加载稳定性

- 动态读取项目版本，避免插件版本号与 Registry 元数据不一致。
- 对 `requests`、`psutil` 等可选依赖使用安全软导入，缺失时只停用对应扩展功能，不阻止 ComfyUI 启动。
- 复核 53 个生产节点、10 个前端扩展和 9 个工作流的注册入口。
- 保持 `AICG3D_*` 命名空间隔离；旧版 Spark-TTS 和 PromptSplit 节点只在不会覆盖其他插件时提供兼容别名。

## 接口与配置安全

- 提示词优化、优化取消、分段清理等接口对损坏 JSON、空 JSON 和错误数据类型统一返回 `400`。
- API Key 不再回传到浏览器，提示词优化配置迁移到 ComfyUI 用户目录。
- 配置写入使用原子替换，避免异常退出产生半份配置文件。
- 分段缓存清理只处理插件自己记录的文件，并校验目录边界、文件后缀和符号链接。
- 临时素材清理限定在 ComfyUI 临时目录中的插件专属子目录。

## 节点与工作流可靠性

- 修复批量填入全部视频提示词时段落节点自动缩放的问题。
- 修复全局提示词折叠、打开资源库和高级参数展开时的节点尺寸变化。
- 修复角色音色库、资源库和最终合成节点在经典节点模式与 Nodes 2.0 下的尺寸跟随和控件显示。
- 完善最终合成 · 高清成片的折叠参数、手动/自动合成、单线成片数据和按开关顺序执行逻辑。
- 验证跳过中间段落、非连续分段、预览刷新、接缝曝光处理和缺失素材提示。

## 内置 Spark-TTS 与角色音色

- 保留内置 Spark-TTS，不要求额外安装独立 Spark 插件才能加载本插件节点。
- 模型或依赖缺失时提供明确的安装与模型路径提示。
- 使用 `soundfile` 写入参考音频，兼容当前 ComfyUI 的 `torchaudio` 环境。
- 继续支持六角色声线座位、跨段音色继承、固定声线描述、试听、重新生成和多人物图像绑定。

## 验证

- Python 全量编译检查通过。
- 10 个前端 JavaScript 文件语法检查通过。
- 23 组节点、工作流、二采、VSR、音色和 Spark-TTS 专项测试通过。
- 发布审计：53 个节点、10 个前端扩展、9 个工作流，0 个错误。
- 经典节点模式与 Nodes 2.0 的真实 ComfyUI 浏览器 UI 烟测通过。
- 冷启动注册 3924 个节点，所有 AICG3D 关键节点均成功注册。
- 损坏 JSON 路由、资源模型文件夹菜单和缺失素材提示完成实际请求验证。
