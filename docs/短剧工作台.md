# 短剧工作台

## 无限时长视频的 MiniMax H3 工作流

短剧工作台是 ComfyUI 上的本地 MiniMax H3 无限长视频插件与工作流。它通过多段顺序生成、上一段尾帧续写、跨段曝光锁定和最终视频合成，让用户可以连续制作短剧、剧情片和长视频。

官方 GitHub 仓库：

https://github.com/JGRFW/comfyui-AICG3D

## 主要功能

- MiniMax H3 本地视频生成
- 无限增加视频段落
- 每段独立提示词、秒数和随机种子
- 上一段视频尾帧续写
- 跨段曝光锁定和接缝处理
- 图片、视频、音频参考素材
- 独立资源库和段落链资源继承
- 提示词优化、技能库和分段提示词解析
- 逐段解码并合成为完整长视频

## 主要工作流

- `workflows/13.AICG3D_MiniMax H3 无限长视频生成工作流1.2.json`
- `workflows/13.AICG3D_无限分段 生视频.json`

## 安装入口

1. 将 `ComfyUI-AICG3D-Integrated` 放入 ComfyUI 的 `custom_nodes` 目录。
2. 重启 ComfyUI。
3. 浏览器执行 `Ctrl+F5`。
4. 打开 13 号无限长视频生成工作流。
5. 根据本机模型文件设置 MiniMax H3 模型、LoRA、步数和加速选项。
