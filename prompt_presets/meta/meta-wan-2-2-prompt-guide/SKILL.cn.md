Wan 2.2  prompt guide


Prompt word formula


The prompt word is used to describe the content and movement process contained in the video. It is a key factor in controlling the content and effect of the video picture. The more complete, accurate and rich the prompt word description is, the higher the quality of the generated video will be, and the closer it will be to the expected content. In order to help you get started faster, we provide two typical formulas for different usage needs:


The basic formula is suitable for new users who are trying AI videos for the first time, and users who use AI videos as inspiration. Simple and free prompts can generate more imaginative videos.

Prompt word = subject + scene + movement

Subject: The subject is the main object of the video content, which can be a person, animal, plant, object or an imaginary object that does not exist physically.

Scene: The scene is the environment in which the subject is located, including the background and foreground. It can be a real space that exists physically or a fictional scene that is imagined.

Movement: Movement includes the specific movement of the subject and the movement state of the non-subject. It can be stillness, small-amplitude movement, large-amplitude movement, local movement or overall momentum.


The advanced formula is suitable for users who have certain experience in using AI videos. Adding richer and more detailed descriptions on top of the basic formula can effectively improve the texture, vividness, and storytelling of the video.

Prompt word = subject (subject description) + scene (scene description) + movement (movement description) + aesthetic control + stylization

Subject description: Subject description is a description of the details of the subject's appearance, which can be listed through adjectives or short sentences, such as "a black-haired Miao girl wearing ethnic minority costumes", "a flying fairy from another world, wearing shabby but gorgeous clothes, with a pair of strange wings made of ruins fragments spread out behind her."

Scene description: Scene description is a description of the details of the characteristics of the subject's environment, which can be listed through adjectives or short sentences.

Motion description: Motion description is a description of the details of the motion characteristics, including the amplitude, rate and effect of the motion, such as "swaying violently", "moving slowly", "breaking the glass".

Aesthetic control: includes light source, lighting environment, scene, viewing angle, lens, camera movement, etc. For common lens language, please refer to the prompt word dictionary below.

Stylization: Stylization is a description of the visual style language, such as "cyberpunk", "line illustration", "wasteland style". For common stylizations, please see the prompt word dictionary below.


The formula image of the graphic video has already determined the subject, scene and style, so the prompt words mainly describe the dynamic process and camera movement requirements.

Cue word = movement + camera movement

Motion description: Combine elements in the image (such as people and animals) to describe their dynamic process, such as running and greeting. Adjectives can be used to control the degree and speed of the movement, such as "quickly" and "slowly".

Camera movement: If you have specific requirements for camera movement, you can control it through prompts such as "camera advance" or "camera left move". If you do not want the camera to change, you can emphasize it through "fixed camera".
