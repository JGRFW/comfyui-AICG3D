# 金政基极繁主义·治愈场景插画 提示词生成模板
一、核心美学理念
金政基极繁主义治愈场景插画的本质是极繁细节+柔润治愈意境的融合，以极致流畅线条与丰富纹理还原场景、人物、物件的真实质感，用强烈且柔和的光影与高饱和和谐色调营造松弛、温暖、治愈的氛围。拒绝杂乱无章的元素堆砌，追求“繁而有序的舒适感”，让每一处细节、每一缕光影、每一种色彩都服务于整体治愈调性，既保留金政基风格的线条张力、极繁构图与钢笔质感，又兼具清新治愈插画的温柔与松弛，实现艺术感与治愈感的双重统一。
二、用户必须提供的核心输入参数
基础场景设定
季节维度：春日/夏日/初秋/深秋/冬日（白天/黄昏/夜晚）
场景类型：「户外」乡村小院/森林秘境/河畔溪边/荷塘菱田/茶田坡地/稻田乡野/复古街巷/露台花园/林间空地 「室内」温馨阳台/庭院小屋/山居客厅
空间尺度：特写/半身/全景/超广角全景/远景
人物核心设定（无人物则标注“无人物”）
人物形象：长发少女/短发女孩/小男孩/年轻女性/家人（可补充气质：温柔/灵动/慵懒/恬静）
服装风格：清新森系/简约日常/温柔复古/田园休闲/飘逸纱裙
服装配色：主色+辅色（例：浅蓝+米白、暖粉+杏色、荷粉+薄荷绿）
人物动作：静态（坐/躺/靠/站/蹲）/动态（浇花/捞花瓣/品茶/散步/捧花/执灯）
情绪状态：悠闲慵懒/温柔平静/灵动愉悦/恬静治愈/温暖闲适
视觉核心设定
主色调：明亮清新绿/暖金落日橙/柔粉晚霞调/水蓝溪涧调/茶青原木棕/荷粉菱绿
画面质感：钢笔插画质感/半写实手绘/电影质感/32K超高清/壁纸质感
核心氛围：梦幻温柔治愈/田园烟火气/岁月静好/水乡悠然/复古怀旧/清新文艺
专属元素设定
核心植物：荷花/月季/绣球/迎春/萱草/蔷薇/茶树/水稻/芦苇/菖蒲/爬山虎/格桑花
核心动物：猫咪/柯基/橘猫/白鹭/水鸟/蝴蝶（无动物则标注“无动物”）
核心物件：藤编桌椅/陶瓷茶具/竹编筐篓/铁艺花架/复古花盆/鱼竿/洒水壶/琉璃灯
光影类型：柔光/逆光/侧逆光/顶光/斑驳树影/黄昏暖光/落日霞光/晴朗柔光
特殊定制要求
强调/规避细节：（例：强调线条细节、规避画面过暗、强调绿植层次、规避元素杂乱）
额外氛围：动态氛围（发丝轻扬/花瓣飘落/溪水流动）/静态氛围感（无动态则标注“无动态”）
三、视觉构建核心逻辑（必须严格遵循）
构图与镜头准则
匹配用户指定空间尺度，全景/超广角全景注重近中远三层景深与画面舒展，突出自然、建筑与生活元素的融合；半身/特写聚焦人物/核心物件，强化细节与情绪表达；远景侧重意境营造，弱化局部细节，突出整体氛围感。全画幅严格遵循金政基极繁主义风格，广角全景、超开阔画卷、大师级构图，笔触清晰有张力，32K超高清、最高画质、细节极致丰富且层次清晰，色彩饱满和谐，还原极繁细节的同时保证画面整体流畅度。
色彩哲学（色即氛围）
春日/夏日→高饱和度明快色调（明亮绿/浅蓝/鹅黄/荷粉），色彩对比柔和，突出生机与清新，画面干净通透
初秋/深秋→中饱和度暖调色系（稻黄/玉米黄/辣椒红/暖棕），色彩偏温润，突出秋意与烟火气，光影柔和鲜明
冬日白天→低饱和度柔暖色系（米白/浅粉/暖橙），冷暖微对比，弱化清冷，突出暖阳温暖
黄昏/夜晚→暖光为主+渐变天空，明暗对比强烈且柔和，以暖光营造治愈静谧氛围
光影逻辑（光即情绪）
悠闲慵懒/岁月静好→柔光/斑驳树影，光影层次柔和，无硬影，突出松弛治愈感
温柔平静/恬静治愈→侧光/侧逆光，轻微光影反差，勾勒人物轮廓，带柔光金边，突出温馨感
灵动愉悦/梦幻治愈→顶光/通透阳光，光影明亮，高饱和搭配柔光，突出灵动梦幻
田园烟火/市井怀旧→暖金黄昏光，强烈明暗对比，还原生活气息与温暖质感
细节与动态构建
材质真实化
植物：叶片脉络清晰、花瓣纹理细腻，绿植疏密有致，花朵形态自然，藤蔓缠绕真实
物件：藤编编织纹理、木质木纹、布艺褶皱、陶瓷釉面、竹编肌理，还原真实触感
人物：服装面料纹理（纱质通透、棉麻质朴、针织细腻）、发丝蓬松轻盈、神态自然生动
动态捕捉（匹配用户指定额外氛围）
有动态→发丝微飘、花瓣轻扬、溪水流动、树叶晃动、动物慵懒活动，幅度轻柔不破坏治愈氛围
无动态→强化静态细节质感，人物/物件姿态舒展，光影静止，突出静谧安稳
有动物→动物姿态呆萌慵懒/灵动自然，与整体氛围融合，成为治愈点缀
四、强制校验准则（每条提示词必须100%通过）
完整包含用户所有核心输入信息，季节、场景、人物、色调等参数无省略、无模糊表述，无人物/无动物/无动态需明确体现
