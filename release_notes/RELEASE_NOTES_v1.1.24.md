# comfyui-AICG3D v1.1.24

![version](https://img.shields.io/badge/version-1.1.24-green)

## 本次更新

### 二采渲染链稳定性升级

- `AICG-渲染器（二采放大）`现在优先使用 H3 V2 Latent 放大器，并继续执行真实的低噪声二次扩散采样。
- 二采采样默认按 4～6 步、约 `0.30～0.35` 降噪运行，减少二采重新生成人物、服装和环境的问题。
- 音频 Latent 在二采阶段保持原样，不会被重新生成或改变时间轴。
- 二采数据可以继续连接下一颗二采节点，每一级都会真实放大并重新采样，不会把原视频直接透传。

### 输出口与工作流迁移

- `AICG-渲染器（一采）`输出顺序调整为：`一采数据 → 一采成片`。
- `AICG-渲染器（二采放大）`输出顺序调整为：`二采数据 → 一采成片 → 成片视频`。
- 旧工作流加载时会根据输出名称自动迁移输出口和连线，避免更新后把一采、二采或保存节点接错。
- 继续连接下一级二采时，优先使用“二采数据”；保存最终成片时使用“成片视频”。

### 二采控件与预览

- `采样预览`、`预览间隔`移动到二采节点参数最下方。
- 预览间隔只在采样预览开启时显示；分块宽高、重叠和渐变只在“二采分块采样”开启时显示。
- 旧工作流会自动迁移控件位置，避免预览、清理和放大参数串位。

### 空视频保护

- 当“一采成片”输出存在下游连线时，一采节点会自动开启 `decode_first_pass`。
- 当二采的“一采成片”输出存在下游连线时，会自动开启 `output_first_pass`。
- 修复 `SaveVideo` 收到的视频为 `None` 后触发 `NoneType object has no attribute get_dimensions` 的报错。

### 工作流同步

- 更新 `12.AICG3D_二彩高清放大.json`。
- 更新 `12.AICG3D_渲染器_二采高清放大.json`。
- 补充二采 V2 放大、分块采样调度、预览顺序和连续二采回归测试。
