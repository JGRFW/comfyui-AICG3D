# comfyui-AICG3D v1.1.13

本次更新优化 MiniMax H3 Aicg 加载器的模型和 LoRA 选择体验，解决模型数量较多时只能在扁平列表中翻找的问题。

## 更新内容

- 加载器下拉菜单按模型实际目录自动分组。
- MiniMax、Krea2、Qwen、LTX2.5、Wan22Animate、Z-Image 等目录显示为可展开文件夹。
- LoRA 下拉支持多层目录，例如 `Krea2/Krea2-风格`。
- 文件夹显示包含的模型数量，并自动定位当前选中项所在目录。
- 保留“最近使用”区域，常用模型无需重复查找。
- 搜索仍可跨目录直接匹配文件名和完整路径。
- 兼容关闭 Nodes 2.0 后的经典节点界面。
- 版本号提升至 `1.1.13`。

## 使用方式

1. 打开 `MiniMax H3 Aicg 加载器`。
2. 点击 `FL2VA 模型`、`REF2VA 模型` 或 LoRA 选择框。
3. 优先展开对应文件夹选择模型。
4. 已知文件名时，直接在搜索框输入关键词即可跨文件夹查找。
