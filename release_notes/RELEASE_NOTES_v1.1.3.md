# comfyui-AICG3D v1.1.3

![license](https://img.shields.io/badge/license-GPL--3.0--or--later-blue)
![comfyui](https://img.shields.io/badge/ComfyUI-custom%20node-1E90FF)
![version](https://img.shields.io/badge/version-1.1.3-green)

本次更新聚焦视频段落节点的编辑布局、资源库稳定性和多段拼接工作流的一致性。

## 1. 视频段落节点布局

- 提示词框改为占据节点的主要伸缩空间，拖高节点时优先扩展提示词编辑区。
- 添加资源库、打开下一段、删除这一段统一固定为底部 32px 操作栏。
- 修掉旧布局中操作栏占用约 228px，导致节点出现大面积空白的问题。
- 资源库展开时，提示词仍至少保留 160px 可编辑高度。
- 资源库面板最高 320px，素材较多时在资源库内部滚动。

## 2. 节点拖动与资源库开关

- 节点拖高后不会被资源库刷新逻辑强制缩回。
- 打开资源库后仍可自由调整节点宽高。
- 修复资源库收起后再次打开无响应的问题。
- 展开、收起、再次展开可以稳定循环。
- 修复资源库收起后节点底部残留大块空白的问题。

## 3. 抽卡与锁定功能移除

- 移除视频段落节点中的抽卡本段、锁定本段和复用上次结果入口。
- 移除对应缓存字段和前端缓存状态。
- 保留添加下一段、打开下一段和删除这一段。
- 避免局部重新生成破坏已经确认的多段拼接结果和接缝连续性。

## 4. 工作流同步

- 更新 `workflows/13.AICG3D_MiniMax H3 无限长视频生成工作流1.2.json`。
- 更新旧版 13 号无限分段工作流中的节点提示和操作说明。
- 移除工作流中已经废弃的抽卡说明。
- 同步最新视频段落节点尺寸与界面状态。

## 5. 插件内容

- `web/minimax_h3_easy_ui.js`
- `h3easy/nodes.py`
- `workflows/13.AICG3D_MiniMax H3 无限长视频生成工作流1.2.json`
- `workflows/13.AICG3D_无限分段 生视频.json`
- 插件版本：`1.1.3`

## 升级方法

1. 更新插件仓库或在 ComfyUI Manager 中更新。
2. 重启 ComfyUI。
3. 浏览器执行 `Ctrl+F5` 强制刷新。
4. 重新打开 13 号无限分段工作流。

节点输入输出接口保持兼容，现有工作流不需要重新搭建。
