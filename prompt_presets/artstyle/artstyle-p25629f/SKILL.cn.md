# 吉卜力工作室风格治愈系动画插画 提示词生成模板
一、核心美学理念
吉卜力工作室风格治愈系动画插画的本质是童话诗意 + 温暖治愈意境的融合，以经典日式手绘动画、柔和水彩笔触与干净细腻线条还原场景、人物、物件的灵动质感，用温暖治愈光影、通透柔和色彩与自然细腻的光影过渡营造松弛、温柔、梦幻的治愈氛围。拒绝写实与3D效果，追求“干净通透、温柔灵动”的童话感，让每一处线条、每一缕光影、每一种色彩都服务于整体的治愈调性，既保留吉卜力宫崎骏动画电影的经典手绘特质，又兼具唯美治愈的温柔氛围，实现动画艺术感与治愈感的双重统一。
二、用户必须提供的核心输入参数
基础场景设定
季节维度：春日 / 夏日 / 初秋 / 深秋 / 冬日（白天 / 晚上）
场景类型：「户外」乡村小院 / 森林秘境 / 海边 / 山间石阶 / 田园花海 / 乡间公路 / 林间小屋 / 山谷溪流 「室内」温馨卧室 / 森林小屋内 / 乡村木屋客厅 / 日式小房间
空间尺度：特写 / 半身 / 全景 / 超广角 / 远景
人物核心设定（无人物则标注“无人物”）
人物形象：长发女孩 / 短发少女 / 悠闲少年 / 邻家女孩（可补充年龄感）
服装风格：日常休闲 / 清新森系 / 日式复古 / 简约田园（单款 / 混搭）
服装配色：主色 + 辅色（例：鹅黄 + 米白、浅蓝 + 浅粉、草绿 + 奶白）
人物动作：静态（躺 / 坐 / 靠 / 站）/ 动态（走 / 跑 / 掬水 / 整理花束 / 散步）
情绪状态：悠闲慵懒 / 温柔平静 / 灵动愉悦 / 治愈静谧
视觉核心设定
主色调：明亮绿色调 / 暖橙调 / 淡蓝调 / 明亮清新调 / 浅粉柔调
画面质感：宫崎骏动画电影质感 / 日式手绘动画 / 柔和水彩质感 / 壁纸质感
核心氛围：闲适美好 / 宁静温暖 / 唯美梦幻 / 岁月静好 / 童话氛围 / 清新治愈
专属元素设定
核心植物：蒲公英 / 蔷薇花 / 油菜花 / 紫藤花 / 银杏叶 / 蕨类植物 / 藤蔓绿植（单种 / 多种）
核心动物：猫咪 / 小鸟 / 蝴蝶 / 松鼠 / 小鹿（无动物则标注“无动物”）
核心物件：摇椅 / 藤编椅 / 竹篮 / 复古行李箱 / 野餐垫 / 花艺篮 / 壁炉 / 吊椅（选 1-3 个核心物件）
光影类型：午后阳光 / 窗边柔光 / 斑驳树影 / 落日霞光 / 暖光漫射 / 夕阳余晖
特殊定制要求
强调 / 规避细节：（例：强调水彩质感、规避画面过暗、强调花瓣动态、规避元素杂乱）
额外氛围：动态氛围（花朵晃动 / 云朵漂移 / 发丝轻扬）/ 静态氛围感（无动态则标注“无动态”）
三、视觉构建核心逻辑（必须严格遵循）
构图与镜头准则
匹配用户指定空间尺度，全景 / 超广角注重场景层次与画面舒展，突出自然与建筑的融合；半身 / 特写聚焦人物 / 核心物件，强化细节与情绪表达；远景侧重意境营造，弱化局部细节，突出整体氛围感。全画幅遵循吉卜力经典手绘动画特质，电影级构图、广角治愈画面，干净细腻线条、柔和水彩笔触，8K超高清、最高画质、细腻渲染，纯手绘动画风格，无写实无3D，还原童话治愈细节的同时保证画面整体流畅通透。
色彩哲学（色即氛围）
春日 / 夏日 → 通透柔和明快色调（明亮绿 / 浅蓝 / 鹅黄），色彩过渡自然，突出生机与清新，画面干净通透
初秋 / 深秋 → 温暖柔润色系（暖橙 / 浅棕 / 金黄），色彩温润柔和，突出秋意的温柔与诗意，光影细腻过渡
冬日白天 → 低饱和度柔暖色系（奶白 / 暖橙 / 浅粉），冷暖柔和对比，弱化冬日清冷，突出暖阳的温暖
冬日晚上 → 柔和冷暖色系（深蓝 + 暖黄 / 暖橙），明暗反差柔和，以暖光中和冷调，突出宁静温暖的氛围感
光影逻辑（光即情绪）
悠闲慵懒 / 岁月静好 → 漫射柔光 / 斑驳树影，光影层次柔和自然，无硬影，洒在人物 / 物件上形成轻量明暗，突出松弛感
温柔平静 / 宁静温暖 → 侧光 / 逆光 + 局部柔光，光影反差轻微，勾勒人物 / 场景轮廓，边缘带轻量柔光，突出温馨感
灵动愉悦 / 童话氛围 → 通透正面光 + 光斑点缀，光影明亮柔和，通透色彩搭配温暖光线，突出画面的灵动与梦幻
治愈静谧 → 低光环境 + 局部暖光，光影反差柔和，大面积柔和暗调搭配小范围亮调，突出画面的静谧与治愈
细节与动态构建
材质真实化
植物：叶片柔软细腻、花瓣纹理清新，绿植有疏密层次，花朵有盛放 / 半开的形态差异，水彩质感自然
物件：木质物件的温润纹理、布艺的柔软褶皱、藤编的自然肌理、竹篮的质朴质感，还原手绘动画触感
人物：服装的面料轻盈柔软、发丝蓬松灵动、神态自然治愈，贴合吉卜力经典人物质感
动态捕捉（匹配用户指定额外氛围）
有动态 → 发丝微飘、花瓣轻扬、树叶晃动、云朵缓慢漂移、动物轻动，动态幅度轻柔，不破坏整体治愈氛围
无动态 → 强化静态细节的质感，人物 / 物件姿态舒展，光影静止，突出画面的静谧与安稳
有动物 → 动物的灵动慵懒姿态、自然互动，与整体氛围融合，成为画面的治愈点缀
四、强制校验准则（每条提示词必须 100% 通过）
完整包含用户所有核心输入信息，季节、场景、人物、色调等参数无省略、无模糊表述，无人物 / 无动物 / 无动态需明确体现
画面主体（人物 / 核心建筑 / 核心物件）始终清晰突出，位于画面视觉中心，无被前景元素遮挡的情况
前景元素（植物 / 小物件）与中景（人物 / 主建筑）、背景（天空 / 远山 / 大海）形成清晰的空间层次，避免画面扁平、元素堆砌
镜头类型与用户指定的空间尺度严格匹配，全景不刻意聚焦局部，特写不盲目扩展场景，保证画面呈现与需求一致
色彩搭配、光影设计与用户指定的主色调、画面质感、情绪状态严格匹配，光影有层次、色彩有协调，无色调混乱、光影突兀问题
同一批次多条提示词在人物服装 / 动作、核心物件、植物种类、动态细节、光影类型上实现显著差异化，无重复表述
文字流畅自然，无专业术语堆砌、无机械编号，符合插画提示词的表达逻辑，读感舒适
季节与场景、植物、服装高度适配（例：冬日不出现油菜花、夏日不出现银杏叶），无场景与元素违和的情况
每条提示词独立完整呈现所有参数，包含风格基底、视觉参数、场景人物、细节氛围，无需额外补充信息即可直接使用
严格保留吉卜力工作室、宫崎骏动画电影、日式手绘动画、水彩笔触、无写实无3D等核心基底词，无遗漏，同时治愈系调性贯穿全程，不偏离核心美学理念
